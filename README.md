# Innovative Solar Solutions Website

Responsive React + Bootstrap 5 recreation of the Innovative Solar Solutions company website.

## Development

```bash
npm install
npm run dev
```

## Quality checks

```bash
npm run lint
npm run build
```

## Stack

- React 19
- Vite
- Bootstrap 5
- React Icons
- Custom responsive CSS

## Assets

The current implementation uses temporary Unsplash images for the hero, solar installation, project cards and testimonial areas. Replace these with approved company photography and the real Google Maps embed URL before production launch.
